# bms-react-admin

# Core npm Commands
# | Command                   | Purpose                           |
# | ------------------------- | --------------------------------- |
# | `npm init -y`             | Create `package.json` quickly     |
# | `npm install` / `npm i`   | Install all dependencies          |
# | `npm i <package>`         | Install a dependency              |
# | `npm i -D <package>`      | Install a dev dependency          |
# | `npm uninstall <package>` | Remove a package                  |
# | `npm update`              | Update installed packages         |
# | `npm outdated`            | Check outdated packages           |
# | `npm audit`               | Scan for vulnerabilities          |
# | `npm audit fix`           | Fix vulnerabilities automatically |
# | `npm list --depth=0`      | List top-level packages           |

# Development & Build Commands
# | Command           | Purpose                                 |
# | ----------------- | --------------------------------------- |
# | `npm run dev`     | Local development server (Vite)         |
# | `npm start`       | Dev server (Create React App)           |
# | `npm run build`   | Create production-ready build           |
# | `npm run preview` | Preview production build locally (Vite) |

# NPX (Scaffolding & One-off Tools)
# | Command                  | Purpose                          |
# | ------------------------ | -------------------------------- |
# | `npx create-vite@latest` | Create Vite + React app          |
# | `npx create-react-app`   | Create CRA app (legacy)          |
# | `npx <tool>`             | Run a package without installing |

# Troubleshooting & Cleanup
# | Command                                 | Purpose                |
# | --------------------------------------- | ---------------------- |
# | `rm -rf node_modules package-lock.json` | Reset dependencies     |
# | `npm install`                           | Reinstall dependencies |
# | `npm cache clean --force`               | Clear npm cache        |

# Files & Folders to Remember
# | Item                | Meaning                         |
# | ------------------- | ------------------------------- |
# | `package.json`      | Project dependencies & scripts  |
# | `package-lock.json` | Exact installed versions        |
# | `node_modules/`     | Installed packages              |
# | `dist/` / `build/`  | Production output (deploy this) |
